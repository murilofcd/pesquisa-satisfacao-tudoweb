# Pesquisa de Satisfação de Atendimento - TudoWeb

Este projeto consiste em um programa desenvolvido em Python para coletar e analisar o nível de satisfação dos clientes da empresa de marketing **TudoWeb** em relação ao atendimento prestado.

---

## 📌 Objetivo
Coletar dados de entrevistados (nome, idade e opinião sobre o atendimento) utilizando estruturas de repetição, validação de entradas e estruturas de decisão, exibindo ao final o relatório com o total de respostas.

---

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python 3
* **Conceitos Aplicados:** 
  * Estruturas de repetição (`for` e `while`)
  * Estruturas condicionais (`if`, `elif`, `else`)
  * Validação e tratamento de exceções (`try / except`)

---

## 📋 Funcionalidades
* Coleta de Nome e Idade.
* Menu de opções de satisfação:
  1. EXCELENTE
  2. BOM
  3. RUIM
* Validação para garantir que apenas dados válidos sejam inseridos.
* Relatório final contendo:
  * Quantidade total de respostas **EXCELENTE**.
  * Quantidade total de respostas **RUIM**.
  * Quantidade total de respostas **BOM**.

---
